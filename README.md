# 🎸 Chinook API

Современный REST API для управления базой данных музыкального магазина **Chinook**. 
Проект построен на принципах **Clean Architecture** с использованием быстрого **Dapper** для работы с базой данных, без использования тяжелых ORM.

## 🛠 Стек технологий

- **Backend:** C# / .NET 10
- **База данных:** PostgreSQL 17 (с расширением `pgvector`)
- **Data Access:** Dapper (Micro-ORM) + Npgsql
- **Контейнеризация:** Docker & Docker Compose
- **API Тестирование:** Bruno (коллекция хранится прямо в репозитории)

## 🏗 Архитектура

Проект разделен на 4 слоя согласно принципам Clean Architecture:
- **`Chinook.Domain`** — бизнес-сущности (Entities). Не имеет внешних зависимостей.
- **`Chinook.Application`** — интерфейсы и контракты (Interfaces).
- **`Chinook.Infrastructure`** — реализации (Repositories, Dapper, Npgsql).
- **`Chinook.API`** — точка входа, контроллеры, DI-конфигурация.

## 🚀 Быстрый старт

### 1. Запуск базы данных
Убедитесь, что у вас установлен Docker. Перейдите в папку `Docker` и выполните:
```bash
cd Docker
docker-compose up -d
```
*Это поднимет PostgreSQL 17 и автоматически создаст схему БД из `init.sql`.*

### 2. Запуск API
Откройте решение `Chinook.slnx` в **Visual Studio 2026** и запустите проект `Chinook.API` (F5).
API будет доступен по адресу: `https://localhost:7090` (порт может отличаться, см. `launchSettings.json`).

### 3. Тестирование API
В корне проекта находится папка `BrunoCollection`. Откройте её в приложении [Bruno](https://www.usebruno.com/) для удобного тестирования эндпоинтов.

## 📡 Текущие эндпоинты

| Метод | Эндпоинт | Описание |
| :--- | :--- | :--- |
| `GET` | `/api/artists` | Получить список всех исполнителей (поддержка `?sortBy=name`) |
| `GET` | `/api/artists/{id}` | Получить исполнителя по ID |
| `POST` | `/api/artists` | Создать нового исполнителя |
| `PUT` | `/api/artists/{id}` | Обновить данные исполнителя |
| `DELETE` | `/api/artists/{id}` | Удалить исполнителя |
